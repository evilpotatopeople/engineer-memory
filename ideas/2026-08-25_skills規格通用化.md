### Landscape 發現（2026-08-25 查證）
1. **Agent Skills 是開放標準**：Anthropic 2025-12-18 於 agentskills.io 開源 SKILL.md 規格、交 Agentic AI Foundation 治理；48 小時內 OpenAI 讓 Codex CLI 原生支援；2026-03 有 32 個工具、2026-06 約 40 個（Codex、Gemini CLI、Cursor、VS Code、Copilot、Goose、Junie…）讀同一份 SKILL.md 同一種目錄結構。
2. **Agent Plugins 1.0**（2026-08-06 發布、AWS/Cursor/GitHub/Vercel 背書）：skills/ + mcp.json 的跨 agent 打包標準——dtc 的 `skills/` + `install.sh` 幾乎就是它的雛形。
3. **分工格局**：SKILL.md＝怎麼做（工作流知識）、AGENTS.md＝專案是什麼、MCP＝工具怎麼接。三者互補不互斥。

### 可行性結論（四點）
1. **論點已證**：「累積在系統、AI 可換」有兩個實證——WSL2 移植（計算層可攜）+ 同事 Codex 實跑（對話層可攜）。
2. **規格免發明**：當初選 skills 資料夾格式等於不小心壓中業界標準；要做的只是「對齊標準 + 清除 Claude Code 專屬假設」，不是設計新規格。
3. **EUREKA——缺口在驗收不在規格**：任何標準都保證不了不同模型執行 580 行 SOP 的品質（參 2026-08-06 Metorik 口徑教訓：工具一樣、判斷力不一樣）。若哪天要認真交付，核心工程物是「跨 agent golden-output 驗收測試」（確定性輸出讓比對便宜、約半天）而非相容層。
4. **維護預算**：bus factor 1 的內部工具，支援矩陣上限＝主平台 Claude Code + 已驗證副平台 Codex，其餘標「理論相容、未驗證」。不做 N 平台矩陣。
